# DevOps Tarot

A complete 78-card DevOps tarot deck built for SREs, platform engineers, and anyone who speaks YAML. Each card reimagines a classic Rider-Waite archetype as a modern infrastructure, observability, or deployment concept. Draw a single card for daily insight or lay out a three-card spread to diagnose your pipeline.

## Features

- **78 Custom Cards** — Major & Minor Arcana mapped to Code, Logs, Bugs, and Servers.
- **Corporate Comic Art Style** — Bold line art, thick expressive outlines, bright cel-shaded colors, and playful cartoon energy generated by GPT-Image-2.
- **AI-Generated Card Text** — Classic tarot name and DevOps title rendered directly into the artwork.
- **Original / DevOps Toggle** — Switch between classic Rider-Waite meanings and enhanced DevOps/SRE interpretations.
- **Interactive Web App** — Single draw, three-card spread (Past / Present / Future), card flips, and searchable card browser.
- **GitHub Pages Ready** — Static site built into `/docs`.

## Quick Start

### 1. Generate card images (OpenAI GPT-Image-2)

```bash
# Generate a test card (back + one front) to verify Style C and text placement
tarotgen-generate --test --regenerate

# Generate the full 78-card deck + back
tarotgen-generate --regenerate

# Resume a partial run (skip existing files)
tarotgen-generate --resume

# Regenerate a specific card
tarotgen-generate --card-id 00-the-fool --regenerate
```

### 2. Build the static site

```bash
tarotgen-build
```

This compiles `docs/index.html`, `docs/cards.html`, `docs/style.css`, `docs/cards-data.json`, and `docs/social-preview.png`.

### 3. Preview locally

Open `docs/index.html` in any browser, or use the built-in server (opens browser automatically):

```bash
tarotgen-serve
```

Or use the standard Python HTTP server:

```bash
cd docs && python -m http.server 8000
```

### 4. Deploy to GitHub Pages

Configure your repository settings to serve from the `/docs` folder on the default branch.

## CLI Entrypoints

After installing the package (`uv pip install -e .` or `pip install -e .`), the following commands are available:

- `tarotgen-generate` — Generate card images via OpenAI GPT-Image-2
- `tarotgen-build` — Build the static site
- `tarotgen-serve` — Start local dev server
- `tarotgen-samples` — Generate style sample previews

## Customization

All prompts, generation settings, and site metadata live in **`site.yml`** at the project root. Edit this file to customize without touching Python code:

- **Switch art styles**: Edit `prompts.card_front` and `prompts.card_back` in `site.yml`.
- **Change generation params**: Edit `generation.model`, `generation.size`, `generation.quality`, etc. in `site.yml`.
- **Change social preview text**: Edit `social_preview.headline`, `social_preview.subheadline`, etc. in `site.yml`.
- **Change domain**: Edit `site.cname` in `site.yml`.
- **Enhance meanings**: Run `tarotgen-generate` to re-generate deeper DevOps terminology using GPT-4o-mini.
- **Enhance scenes**: Run `tarotgen-generate` to enrich card descriptions with more specific technical imagery.
- **Toggle datasets**: Edit `meanings.json` and `meanings_original.json`, then rebuild the site.
