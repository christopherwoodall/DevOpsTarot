# DevOps Tarot

A complete 78-card DevOps tarot deck built for SREs, platform engineers, and anyone who speaks YAML. Each card reimagines a classic Rider-Waite archetype as a modern infrastructure, observability, or deployment concept. Draw a single card for daily insight or lay out a three-card spread to diagnose your pipeline.

## Features

- **78 Custom Cards** — Major & Minor Arcana mapped to Code, Logs, Bugs, and Servers.
- **Corporate Comic Art Style** — Bold line art, thick expressive outlines, bright cel-shaded colors, and playful cartoon energy generated by GPT-Image-2.
- **AI-Generated Card Text** — Classic tarot name and DevOps title rendered directly into the artwork.
- **Original / DevOps Toggle** — Switch between classic Rider-Waite meanings and enhanced DevOps/SRE interpretations.
- **Interactive Web App** — Single draw, three-card spread (Past / Present / Future), card flips, searchable codex, and synth sound effects.
- **GitHub Pages Ready** — Static site built into `/docs`.
